# 💰 MONEY CLICKER

クリックでお金を稼ぐ、シンプルな Cookie Clicker 風クリッカーゲーム。

## 遊び方
- 中央のコインをクリックして稼ぐ
- 「ビジネス」タブ … 自動で毎秒お金を生む（レモネードスタンド〜テック企業の10種）
- 「クリック強化」タブ … 1クリックの獲得額を増やす（6種）
- 価格は購入するごとに1.15倍に上昇
- 離席中も自動収入が入る（最大8時間）
- セーブはブラウザ内（localStorage）に自動保存。フッターの「リセット」で最初から

## 構成
- `index.html` … 画面とスタイル
- `js/game.js` … ゲームロジック
- `js/version.js` … 更新履歴
